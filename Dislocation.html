2. 柏氏矢量计算全集

I. 基础坐标设定

基于单位晶胞边长 $a = 1$，建立如下基准坐标：

$$D(0, 0, 0) \quad \text{(原点)}$$ $$A(1/2, 1/2, 0) \quad \text{(底面面心, z=0)}$$ $$B(1/2, 0, 1/2) \quad \text{(侧面面心, y=0)}$$ $$C(0, 1/2, 1/2) \quad \text{(侧面面心, x=0)}$$

II. 四面体各面中心坐标

对面法则：几何中心为面上三顶点的算术平均 $(x,y,z) = (P_1+P_2+P_3)/3$：

$$\delta \, (\triangle ABC\text{中心}) = \left(\frac{1}{3}, \frac{1}{3}, \frac{1}{3}\right)$$ $$\alpha \, (\triangle BCD\text{中心}) = \left(\frac{1}{6}, \frac{1}{6}, \frac{1}{3}\right)$$ $$\beta \, (\triangle ACD\text{中心}) = \left(\frac{1}{6}, \frac{1}{3}, \frac{1}{6}\right)$$ $$\gamma \, (\triangle ABD\text{中心}) = \left(\frac{1}{3}, \frac{1}{6}, \frac{1}{6}\right)$$

III. 全位错 (Perfect Dislocations)

矢量形式 $\frac{a}{2}\langle 110 \rangle$：

$$DB = \frac{1}{2}[1, 0, 1], \quad DC = \frac{1}{2}[0, 1, 1], \quad DA = \frac{1}{2}[1, 1, 0]$$ $$BC = \frac{1}{2}[-1, 1, 0], \quad AB = \frac{1}{2}[0, -1, 1], \quad AC = \frac{1}{2}[-1, 0, 1]$$

IV. Shockley 不全位错 (Partial Dislocations)

矢量形式 $\frac{a}{6}\langle 112 \rangle$：

$$B\alpha = \frac{1}{6}[-2, 1, -1], \quad C\alpha = \frac{1}{6}[1, -2, -1], \quad D\alpha = \frac{1}{6}[1, 1, 2]$$ $$A\beta = \frac{1}{6}[-2, -1, 1], \quad C\beta = \frac{1}{6}[1, -1, -2], \quad D\beta = \frac{1}{6}[1, 2, 1]$$ $$A\gamma = \frac{1}{6}[-1, -2, 1], \quad B\gamma = \frac{1}{6}[-1, 1, -2], \quad D\gamma = \frac{1}{6}[2, 1, 1]$$ $$\delta A = \frac{1}{6}[1, 1, -2], \quad \delta B = \frac{1}{6}[1, -2, 1], \quad \delta C = \frac{1}{6}[-2, 1, 1]$$

V. 弗兰克位错 (Frank Partials)

矢量形式 $\frac{a}{3}\langle 111 \rangle$：

$$A\alpha = \frac{1}{3}[-1, -1, 1], \quad B\beta = \frac{1}{3}[-1, 1, -1]$$ $$C\gamma = \frac{1}{3}[1, -1, -1], \quad D\delta = \frac{1}{3}[1, 1, 1]$$

VI. 压杆位错 (Stair-rod Dislocations)

矢量形式 $\frac{a}{6}\langle 110 \rangle$：

$$\alpha\beta = \frac{1}{6}[0, 1, -1], \quad \alpha\gamma = \frac{1}{6}[1, 0, -1], \quad \alpha\delta = \frac{1}{6}[1, 1, 0]$$ $$\beta\gamma = \frac{1}{6}[1, -1, 0], \quad \beta\delta = \frac{1}{6}[1, 0, 1], \quad \gamma\delta = \frac{1}{6}[0, 1, 1]$$
